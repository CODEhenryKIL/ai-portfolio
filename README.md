# SK hynix AI 해커톤 포트폴리오

길민규의 지원용 포트폴리오를 GitHub Pages에서 열람하기 위한 정적 사이트입니다.

## 구성

- `index.html` — 16페이지 포트폴리오 뷰어
- `styles.css` — 반응형 화면 및 인쇄 스타일
- `script.js` — 현재 장 표시를 위한 점진적 향상 스크립트
- `assets/slide-01.png` … `slide-16.png` — 고해상도 슬라이드
- `assets/SK_hynix_Portfolio.pdf` — 링크가 포함된 PDF

JavaScript가 꺼져 있어도 모든 페이지와 목차 링크, PDF 열기 및 다운로드 기능을 사용할 수 있습니다.
